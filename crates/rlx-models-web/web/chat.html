Reasoning that reaches this many tokens is closed for it ("give the solution based on the thinking directly now") and the model answers — a small model can otherwise reason in circles until the context is full.
Workers run 4 positions per step: long prompts go in 4 at a time, and each step also checks up to 3 tokens guessed from earlier text, keeping the ones the model agrees with — sampled, a guess is kept with the probability the model gives it, so answers are drawn exactly as without guessing.
